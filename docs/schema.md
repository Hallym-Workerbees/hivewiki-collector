# 데이터베이스 스키마

HiveWiki Collector는 HiveWiki 통합 DB 중 RSS 수집에 필요한 일부 테이블만 직접 사용합니다.

이 repository의 [schema.sql](../schema.sql)은 collector가 직접 읽고 쓰는 subset만 문서화합니다.

## 관계

```text
sources
  1 -> N source_documents
  1 -> N ingestion_jobs through source_documents

source_documents
  1 -> 1 ingestion_jobs
```

## `sources`

RSS source와 polling 상태를 저장합니다.

| Column | Type | 설명 |
| --- | --- | --- |
| `id` | `BIGINT GENERATED BY DEFAULT AS IDENTITY` | source id입니다. metric의 `source` label에도 이 값을 사용합니다. |
| `name` | `TEXT` | source 이름입니다. 사람이 읽기 위한 값이며 metric label로 사용하지 않습니다. |
| `target_url` | `TEXT` | RSS feed URL입니다. metric label로 사용하지 않습니다. |
| `enabled` | `BOOLEAN` | source 활성화 여부입니다. |
| `poll_interval_minutes` | `INTEGER` | polling 간격입니다. |
| `next_poll_at` | `TIMESTAMPTZ` | 다음 polling 예정 시각입니다. |
| `initial_backfill_done` | `BOOLEAN` | 최초 backfill 완료 여부입니다. |
| `backfill_completed_at` | `TIMESTAMPTZ` | backfill 완료 시각입니다. |
| `last_polled_at` | `TIMESTAMPTZ` | 마지막 polling 시도 시각입니다. |
| `last_success_at` | `TIMESTAMPTZ` | 마지막 성공 시각입니다. |
| `last_error_at` | `TIMESTAMPTZ` | 마지막 실패 시각입니다. |
| `last_error_message` | `TEXT` | 마지막 실패 메시지입니다. |
| `consecutive_failures` | `INTEGER` | 연속 실패 횟수입니다. |
| `created_at` | `TIMESTAMPTZ` | 생성 시각입니다. |
| `updated_at` | `TIMESTAMPTZ` | 수정 시각입니다. |

### Polling 동작

Collector는 `enabled = TRUE`이고 `next_poll_at <= NOW()`인 source를 가져옵니다. source를 claim할 때 `last_polled_at`과 다음 `next_poll_at`을 갱신합니다.

처리 성공 시:

- `last_success_at`을 갱신합니다.
- `last_error_at`, `last_error_message`를 비웁니다.
- `consecutive_failures`를 `0`으로 초기화합니다.
- 최초 backfill이면 `initial_backfill_done`을 `TRUE`로 변경합니다.

처리 실패 시:

- `last_error_at`, `last_error_message`를 갱신합니다.
- `consecutive_failures`를 증가시킵니다.
- 다음 polling 시각을 다시 계산합니다.

## `source_documents`

RSS에서 수집한 문서를 저장합니다.

| Column | Type | 설명 |
| --- | --- | --- |
| `id` | `BIGINT GENERATED BY DEFAULT AS IDENTITY` | source document id입니다. |
| `source_id` | `BIGINT` | `sources.id`를 참조합니다. |
| `canonical_url` | `TEXT` | 문서의 canonical URL입니다. |
| `title` | `TEXT` | RSS entry title입니다. |
| `published_at` | `TIMESTAMPTZ` | RSS entry 발행 시각입니다. |
| `body_text` | `TEXT` | RSS content 또는 summary에서 추출한 본문 텍스트입니다. |
| `fetch_status` | `VARCHAR(20)` | 문서 본문 fetch 상태입니다. |
| `fetch_retry_count` | `INTEGER` | fetch retry 횟수입니다. |
| `fetch_error_message` | `TEXT` | fetch 실패 메시지입니다. |
| `wiki_status` | `VARCHAR(20)` | wikifier dispatch와 처리 상태입니다. |
| `collected_at` | `TIMESTAMPTZ` | collector가 문서를 수집한 시각입니다. |

`source_id`, `canonical_url` 조합은 unique입니다. 같은 source에서 같은 canonical URL이 다시 들어오면 새 문서로 저장하지 않습니다.

### `fetch_status`

현재 collector는 RSS content 또는 summary에서 바로 `body_text`를 구성합니다.

- `DONE`: `body_text`가 있는 상태
- `PENDING`: `body_text`가 없는 상태

### `wiki_status`

wikifier로 넘기는 상태를 나타냅니다.

- `NOT_REQUESTED`: 아직 wikifier queue 대상이 아닌 상태
- `QUEUED`: ingestion job이 생성되었거나 Redis queue에 dispatch된 상태
- `FAILED`: Redis queue dispatch가 실패한 상태
- `DEAD`: retry 한도를 초과해 더 이상 처리하지 않는 상태

## `ingestion_jobs`

wikifier로 dispatch할 작업을 저장합니다.

| Column | Type | 설명 |
| --- | --- | --- |
| `id` | `BIGINT GENERATED BY DEFAULT AS IDENTITY` | ingestion job id입니다. |
| `source_document_id` | `BIGINT` | `source_documents.id`를 참조합니다. |
| `status` | `VARCHAR(20)` | job 처리 상태입니다. |
| `retry_count` | `INTEGER` | dispatch retry 횟수입니다. |
| `error_message` | `TEXT` | 마지막 dispatch 실패 메시지입니다. |
| `queued_at` | `TIMESTAMPTZ` | job 생성 시각입니다. |
| `started_at` | `TIMESTAMPTZ` | dispatch claim 시각입니다. |
| `completed_at` | `TIMESTAMPTZ` | 완료 시각입니다. |

`source_document_id`는 unique입니다. 하나의 source document에는 하나의 ingestion job만 생성됩니다.

### `ingestion_jobs.status`

- `QUEUED`: dispatch 대기 상태
- `PUBLISHING`: collector가 dispatch를 위해 claim한 상태
- `ENQUEUED`: Redis queue에 dispatch된 상태
- `FAILED`: dispatch 실패 후 retry 가능한 상태
- `DEAD`: retry 한도를 초과한 상태

## Index

| Index | 대상 | 목적 |
| --- | --- | --- |
| `idx_sources_due_poll` | `sources(enabled, next_poll_at)` | 실행 가능한 source 조회 |
| `idx_source_documents_source` | `source_documents(source_id, collected_at DESC)` | source별 최근 문서 조회 |
| `idx_source_documents_wiki_status` | `source_documents(wiki_status)` | 문서 상태별 count와 조회 |
| `idx_ingestion_jobs_status` | `ingestion_jobs(status, queued_at)` | dispatch 가능한 job 조회 |
| `idx_ingestion_jobs_source_document` | `ingestion_jobs(source_document_id)` | source document 기준 job 조회 |

## 날짜와 시간

DB timestamp는 `TIMESTAMPTZ`를 사용합니다.

Redis queue payload로 전달되는 문서 발행 시각은 Python `datetime.isoformat()` 결과입니다.

예시:

```text
2026-05-24T18:30:00+09:00
```

RSS source가 timezone 없는 값을 제공하면 timezone 없는 ISO 문자열이 전달될 수 있습니다.

```text
2026-05-24T18:30:00
```
